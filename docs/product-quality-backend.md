## Quality checks

Check public responses on demand and use existing delivery records and paper-thesis snapshots for historical analysis. The API does not record response samples, run a settlement collection job, or keep a separate QA history. Historical card impressions cannot be reconstructed from current rankings.

Treat social pagination cursors as opaque. The All feed authenticates and encrypts the paper snapshot inside its cursor with a key derived from the existing JWT secret. If that secret is rotated, restart pagination from the first page. Following and history keep their existing keyset cursors.

## Prompt A/B

`node --import tsx apps/api/src/product-quality-prompt-ab.ts` is dry-run by default. Use a dedicated capped key when possible; shared-key mode is explicit, uses request-level price and token ceilings, and skips Decisions calls because that endpoint doesn't offer the same ceilings. `--scout-only` requires a dedicated capped key and cannot be combined with `--use-configured-key`. No request is automatically retried. Supply `HUNCH_QA_BLIND_SEED` privately; grade A/B before running `--reveal`. Fixtures are public, abridged and not representative of all traffic. Do not promote a variant on this small pilot. Keep model decisions separate from research truth and from quote/identity gates.

2026-11-18 pilot: 6 blinded pairs, 12 responses, $0.0476177 reported. Baseline favored for all 3 map fixtures (two slight); writer candidate favored on 2 with one tie, but neither version cleared the bar for the older shared-context example. Both map variants asserted missing verdict status without enough evidence in the fiction-versus-trial fixture. No prompt defaults changed.

Separate Jev-only extension: 3 blinded pairs, 6 decisions, $0.000139272 reported. Both prompts selected the same lead in every pair—including the explicitly stale case. Confidence shifted without improving the decision. The 18 combined calls cost $0.047756972.
